# Security Policy

Please report suspected vulnerabilities privately through the repository security advisory mechanism. Do not open a public issue containing exploit details, tokens, personal data, or sensitive logs.

Include the affected version, safe reproduction, impact, and masked evidence. Maintainers will acknowledge a report within three business days, assess severity and reachability, and coordinate remediation and disclosure.

Only the latest released minor line receives security fixes during initial development. This policy will be expanded before the first stable release.
